1. Números Racionales (ℚ)

Fracciones, decimales y operaciones básicas.

Definición Clave

Los números racionales se representan como mn donde m y n son enteros, n ≠ 0.

Ejemplos:
  • • 34, -52, 0.75, -1.2
  • • Todos los enteros son racionales (5 = 51)
Decimales periódicos:
  • • 0.333... = 13
  • • 0.1̄ = 19
  • • 0.̄7 = 79

Suma y Resta

Necesitan común denominador.

Ejemplo

23 + 14 = 812 + 312 = 1112

mcm(3,4) = 12

ERROR COMÚN

NO sumar directamente: 23 + 14 ≠ 37

Multiplicación y División

Multiplicación: num×num / den×den. ¡Simplificar antes!

Multiplicación

23 × 94 = 11 × 32 = 32

División

23 ÷ 45 = 23 × 54 = 56

Multiplicar por el recíproco

Conversión Decimal ↔ Fracción

Decimal exacto

0.3 = 310

0.25 = 14

Periódico simple

0.̄3 = 13

0.̄7 = 79

Periódico compuesto

0.1̄6 = 16

Reglas de Signos

Multiplicación/División:

  • (+) × (+) = (+) · (-) × (-) = (+)
  • (+) × (-) = (-) · (-) × (+) = (-)

Suma/Resta (mismo signo):

  • Sumar valores, conservar signo
  • Ej: (-3) + (-5) = -8

2. Potencias y Propiedades

Domina las leyes de exponentes.

Definición

an = a × a × ... × a (n veces)

a = base, n = exponente

am · an

Misma base

= am+n

Ej: 2³ · 2² = 25 = 32

am ÷ an

Misma base

= am-n

Ej: 54 ÷ 5² = 25

(am)n

Potencia de potencia

= am·n

Ej: (2³)² = 26 = 64

am · bm

Mismo exponente

= (a·b)m

Ej: 2³ · 5³ = 10³

am ÷ bm

Mismo exponente

= (a÷b)m

Ej: 6³ ÷ 2³ = 3³

Especiales

Valores clave

a0 = 1 (a≠0)
a1 = a
a-n = 1/an

Ejemplo: Expresar como única potencia

1

Ejercicio:

64 · 64 · 16

2

Base común:

64 = 4³, 16 = 4²

3

Resolver:

4³ · 4³ · 4² = 4(3+3+2) = 48

Verdadero o Falso

(a³)² = a6 VERDADERO
a³ · a² = a6 FALSO → a5
(a·b)³ = a³ · b³ VERDADERO

3. Raíces y Números Reales

De la raíz cuadrada hasta la simplificación completa.

Relación Fundamental

am/n = n√am

n√am = am/n

Vocabulario: En n√a, n = índice, a = cantidad subradical. Sin índice = 2.

Producto (mismo índice)

n√a · n√b = n√(a·b)

Ej: √2 · √8 = √16 = 4

Cociente (mismo índice)

n√a ÷ n√b = n√(a÷b)

Ej: √18 ÷ √2 = √9 = 3

Raíz de Raíz

m√(n√a) = m·n√a

Ejemplo:

√(√16) = 4√16 = 2

Simplificar Raíces

Descomponer en factores primos:

√12 = ?

12 = 4 × 3 = 2² × 3

√12 = √4 · √3 = 2√3

Índice mayor que 2:

3√32 = ?

32 = 8 × 4 = 2³ × 4

= 2·3√4

Raíces Semejantes

Mismo índice y misma cantidad subradical.

3√2 + 5√2 = 8√2

8√7 - √7 + 3√6 - 4√6 = 7√7 - √6

Restricción Importante

Raíces de negativos con índices pares NO están en ℝ.

✓ Válido:

3√(-64) = -4

√25 = 5

✗ No válido:

√(-16) → No existe en ℝ

4√(-81) → No existe

6. Racionalización

Eliminar raíces del denominador.

Caso 1

Denominador con raíz simple

Multiplicar numerador y denominador por la misma raíz.

1√a × √a√a = √aa

Ejemplo:

1/√7 = (1·√7)/(√7·√7) = √7/7

Caso 2

Suma/resta de raíces

Usar el conjugado: cambiar el signo del segundo término.

1√a + √b × √a - √b√a - √b = √a - √ba - b

Recuerda: (√a + √b)(√a - √b) = a - b

Ejemplo paso a paso:

2/(√7 - 1) · (√7 + 1)/(√7 + 1)

= 2(√7 + 1) / [(√7)² - (1)²]

= 2(√7 + 1) / (7 - 1)

= 2(√7 + 1) / 6

= (√7 + 1) / 3

Caso 3

Raíz cúbica en denominador

Para 3√a, multiplicar por 3√a².

Ejemplo:

1/3√5 = 3√25 / 5

Error Común

Racionalizar 1/(2√2):

Incorrecto: multiplicar solo por √2

Correcto: √2/(2·2) = √2/4
